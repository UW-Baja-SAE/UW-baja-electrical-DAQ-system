# GitHub Workflow

This repository is used to develop and document the UW Baja Electrical DAQ System.

## 1. Future Repository Structure

```text
docs/       → Documentation
hardware/   → Schematics, wiring, PCB, BOM
firmware/   → Arduino / MCU code
tests/      → Test procedures and results
data/       → Experimental data
analysis/   → Data analysis
```
Put your work in the appropriate folder. If unsure, ask before creating a new folder.

## 2. Do not work directly on ```main```
```main```should contain stable and tested work
