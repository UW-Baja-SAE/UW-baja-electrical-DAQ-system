#Engine RPM

Firmware for measuring engine RPM using a Hall-effect sensor.

## Current Status

- Hall-effect sensor connected to Arduino
- Magnet detection successfully verified
- RPM calculation: In progress

## Development Stages

1. Verify magnet detection
2. Detect sensor pulses
3. Measure pulse period
4. Calculate RPM
5. Validate RPM measurement
6. adding independent power source and storage
